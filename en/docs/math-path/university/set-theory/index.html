Starting from the empty set: the structure and operations of sets

This article is not marked ready yet and only shows in preview mode.

Set theory is the foundational language of modern mathematics. It provides a unified framework for the entire mathematical world.

Core Concepts

∅ Empty Set

The purest “monad”, containing no elements. It is the starting point of the entire mathematical universe.

∈ Membership

The fundamental relation between elements and sets. $a \in A$ means $a$ is an element of set $A$.

⊆ Subsets

The inclusion relation. $A \subseteq B$ means every element of $A$ is in $B$.

∪ ∩ Operations

Union and intersection - the basic algebraic operations on sets.
