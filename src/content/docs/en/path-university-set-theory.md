<p class="intro">Set theory is the foundational language of modern mathematics. It provides a unified framework for the entire mathematical world.</p>

<h2>Core Concepts</h2>
<div class="concepts-grid">
<div class="concept-card card">
<h3>∅ Empty Set</h3>
<p>The purest “monad”, containing no elements. It is the starting point of the entire mathematical universe.</p>
</div>
<div class="concept-card card">
<h3>∈ Membership</h3>
<p>The fundamental relation between elements and sets. $a \in A$ means $a$ is an element of set $A$.</p>
</div>
<div class="concept-card card">
<h3>⊆ Subsets</h3>
<p>The inclusion relation. $A \subseteq B$ means every element of $A$ is in $B$.</p>
</div>
<div class="concept-card card">
<h3>∪ ∩ Operations</h3>
<p>Union and intersection - the basic algebraic operations on sets.</p>
</div>
</div>
