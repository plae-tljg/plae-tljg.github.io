## LibreOffice

LibreOffice is installed by default on Ubuntu.

## WPS Office

Download the .deb file from the [WPS website](https://www.wps.com/download/):

```bash
sudo dpkg -i wps-office_11.x.x.x_amd64.deb
sudo apt --fix-broken install
```
