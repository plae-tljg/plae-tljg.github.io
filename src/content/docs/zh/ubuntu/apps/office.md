## LibreOffice

Ubuntu 默认已安装 LibreOffice。

## WPS Office

从 [WPS 官网](https://www.wps.com/download/) 下载 .deb 文件：

```bash
sudo dpkg -i wps-office_11.x.x.x_amd64.deb
sudo apt --fix-broken install
```
