## GNOME Tweaks

```bash
sudo apt install gnome-tweaks
```

## 自定义工具

### SSH Key Manager

GUI 工具，用于创建和管理 SSH 密钥：

```bash
sudo dpkg -i ssh-manager_1.0.0_amd64.deb
```

### ShareBoard

```bash
sudo dpkg -i shareboard_1.0.0_all.deb
```

### Daily Commands

```bash
sudo dpkg -i daily-commands.deb
```
