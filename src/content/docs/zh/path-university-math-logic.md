<h2>逻辑的核心：形式本身</h2>
<p>数理逻辑正好对应第二个原则：机械化推演。做证明时，可以暂时不管内容，只跟着形式推。</p>

<p>逻辑的核心就是形式本身。给定一串符号，它只根据规则变换符号，不关心符号代表什么。比如最经典的肯定前件：从“若 P 则 Q”和“P”，直接推出“Q”。不需要知道 P 是不是“天在下雨”，Q 是不是“地会湿”，只看到这个形状，就执行这个操作。这就是逻辑的机器性——它像一台只看语法不看语义的自动机。</p>

<h2>空间性与时间性</h2>
<p>进一步观察会发现，逻辑定理本身似乎带有某种空间性和时间性。有些逻辑定理偏空间，比如合取的交换律：“P 且 Q”等价于“Q 且 P”，这说的是两个命题放在一起，左右顺序无所谓，是空间的并列关系。又比如析取的结合律，括号可以重新分配，像是把几个容器在空间里重新摆布。这些定理处理的是静态结构，是同一时刻下的布局。</p>

<p>另一些逻辑定理则偏时间。最典型的就是蕴含的传递性：如果 P → Q 且 Q → R，那么 P → R。这明显带有链条和过程的意味——从第一步到第二步，最后得到从起点到终点的直达路径。这对应的是推导步骤的先后顺序，是线性的时间流动。再比如演绎定理：若要证明“若 P 则 Q”，可以先假设 P，然后一步一步推出 Q，最后把整个推导打包成一个蕴含式。这就像在时间中走了一段路，然后把这段路程折叠成一个静态的箭头。</p>

<p>逻辑虽然号称纯形式，但它的形式本身是从人类对空间并置和时间先后的最原始经验里抽象出来的。可以说，逻辑就是把空间结构（并列、嵌套、替换）和时间结构（先后、步骤、过程）纯粹化为符号操作规则的结果。</p>

<h2>三原则在逻辑中的体现</h2>
<p>这就连回了第一个原则和第三个原则。逻辑系统本身也有基础元素和运算：命题是基本概念，连接词（且、或、非、蕴含）就是运算。从最简单的命题开始，用连接词不断复合，就像从空集开始用幂集和笛卡尔积不断生成新集合一样，由一生多。然后这些复合命题彼此碰撞，用推理规则产生新命题——这就是第三个原则在逻辑里的体现。比如 (P ∧ Q) → P 这个永真式，它本身就体现了“且”和“蕴含”两个概念在形式推导的空间里确立了一条永恒不变的定理。</p>

<p>更有意思的是，当逻辑回过头来审视自己时，就出现了元逻辑。逻辑系统本身也可以被当作一个数学对象来研究：它是否一致？是否完备？这就像之前在集合论里把“关系”对象化成集合一样，元逻辑把“证明”本身也对象化了。这完全是同样的模式——人的思想需要找到现实载体，而“证明过程”这个原本流动在时间中的东西，被捕捉下来，变成了可以静态分析的对象。</p>

<h2>从做数学到看清做数学本身</h2>
<p>数理逻辑的学习，骨子里是第二原则的彻底化：把自己训练成一台完美的符号处理机，在纸面上只做形式推演。但与此同时，也能退后一步，意识到这些形式规则的深层结构——空间性的并列替换，时间性的步骤传递——从而理解为什么这套形式系统能捕捉人类推理的本质。这是本科阶段一个非常深刻的转折：从“做数学”到“看清做数学这件事本身的形状”。</p>
