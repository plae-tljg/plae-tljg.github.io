<p class="intro">Analysis studies the mathematics of continuous quantities. Humanity discovered a crack in numbers themselves - some lengths cannot be expressed by rational numbers, and this is where real numbers were born.</p>

<h2>Real Number Axioms: Accepting the “Night of Continuity”</h2>
<div class="concept-card card">
<p>Completeness axiom: Every non-empty set bounded above has a least upper bound. This is not construction, but acceptance - declaring that the real line has no gaps.</p>
</div>

<h2>Five Equivalent Propositions</h2>
<div class="five-equivalents">
<div class="equiv-item">
<h3>1. Supremum Principle</h3>
<p>Non-empty sets bounded above have supremum</p>
</div>
<div class="equiv-item">
<h3>2. Monotone Convergence</h3>
<p>Monotone bounded sequences converge</p>
</div>
<div class="equiv-item">
<h3>3. Nested Intervals</h3>
<p>Nested intervals with length → 0 intersect at one point</p>
</div>
<div class="equiv-item">
<h3>4. Bolzano-Weierstrass</h3>
<p>Every bounded sequence has a convergent subsequence</p>
</div>
<div class="equiv-item">
<h3>5. Cauchy Criterion</h3>
<p>Terms getting closer to each other must converge</p>
</div>
</div>

<h2>Important Theorems</h2>
<div class="theorem-card card">
<h3>Intermediate Value Theorem</h3>
<p>Continuous function on closed interval takes every value between endpoints.</p>
</div>
<div class="theorem-card card">
<h3>Extreme Value Theorem</h3>
<p>Continuous function on closed interval attains maximum and minimum.</p>
</div>
<div class="theorem-card card">
<h3>Fundamental Theorem of Calculus</h3>
<p>Differentiation and integration are inverse operations.</p>
</div>
